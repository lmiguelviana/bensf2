# 🤖 AGENTS.md - Regras e Instruções Persistentes do BenSF2

## Diretrizes de Projeto
1. **Estética DAW High-End**: Manter o design em padrão Nord Stage / Kontakt / MainStage com dark glassmorphism.
2. **Presets Nativos**: Presets devem abrir caixas de diálogo nativas do Windows (`showSaveDialog` e `showOpenDialog`).
3. **Escala de Semitones**: O seletor no mixer exibe a faixa exata de **0 a +12 semitones**.
4. **Semitones & Módulos OFF por Padrão**: Módulos de efeito por pista começam desligados (OFF) até o usuário ativá-los.
5. **Automação Git**: Sempre realizar commit e push para o repositório `https://github.com/lmiguelviana/bensf2.git` na branch `main`.
